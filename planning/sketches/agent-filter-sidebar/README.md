# Bộ lọc bên trái, dễ đọc chuỗi lựa chọn; tốn bề ngang và chuyển thành xếp dọc trên màn hình nhỏ.

Bản mới: mở `v2.html` — tách Đơn vị/Đội, đối chiếu Excel, giữ node crawl chưa khớp. `index.html` là V1 lưu so sánh. Mockup độc lập, không kết nối database. Tên và cây đơn vị từ snapshot 2026-09-12; không có số liệu usage hoặc tài khoản giả. Bấm Agent → Phòng ban → Đơn vị hoặc nút tình huống mẫu. User chỉ minh họa, chưa nối danh bạ.

Dùng select native, tông tối tương tự dashboard. Mở index.html trực tiếp; không cần build. Hàm window.runChecks() kiểm tra các tình huống chính trong trình duyệt.
